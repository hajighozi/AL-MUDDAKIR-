# R-136 — Turats Knowledge Engine

7 provider dan 20 judul kandidat; pemetaan ke ID Fashl yang sudah ada. Referensi dan atribusi pengarang merupakan daftar kerja, belum verifikasi edisi dan isi. KitabPedia PRO, Kitabpedia.id dan KitabPedia Source internal tidak disamakan. Shamela SDK memerlukan API key resmi, LICENSE belum ditemukan; Turath MCP README dan lisensi MIT kode diperiksa, API nyata dan hak korpus belum diuji. Tidak ada kode, teks kitab, dataset, kredensial atau Git remote eksternal yang diimpor.

Gerbang validasi memeriksa kelengkapan metadata saja, bukan kebenaran klaim atau identitas reviewer. Status tetap draf. Edisi, juz/halaman, dalil, bukti, perbedaan redaksi, hak penggunaan dan review manusia diperlukan. Untuk Qur’an, periksa teks dan qira’at; untuk hadis, identitas riwayat, sanad/matan, takhrij dan syarah. Jangan menganggap sumber digital yang saling menyalin sebagai saksi independen.

Peta kitab mencakup rujukan klasik dan buku ajar modern; hak reproduksi setiap edisi perlu ditinjau. Tidak ada materi penuh dipublikasikan. Pemeriksaan konstruksi: 67 lulus. Browser nyata belum diuji.
