# SP-04 / RBX-01 — Original Roblox Learning World
2026-11-27. Status COMMITTED/DRAFT design only. Preserve WORK_PLAN.md, SP-04 and all existing audit mandates.
## User mandates recorded in this session
- Opening lets learners choose class and material.
- Learners can ask questions; teacher inside game explains with simple answers.
- Virtual graduation inspired by Minecraft graduation precedent (specific event not verified); implement original ceremony in Roblox, not accredited graduation.
- Introduce game via YouTube promotion to parents; invite parents to play with children, voluntarily.
- Build manually in Roblox Studio. Own ideas; no copying APKs, game code, maps or assets from other games.
- Update frequently when early interest grows; improve on feedback, do not engineer compulsive play.
## Proposed original experience
Working title Raudhah's Dome Roblox Learning World, not final brand. First place: Nagari Ilmu with original low-poly Sumatera-inspired campus, classroom selection, subject rooms, teacher NPC, practice, optional reflection and family demo. First prototype: one class, one topic (water cycle, proposed only), three curated questions and answers, one practice task, completion feedback. Expand to six faculty routes after source validation. IQRA observe/ask, FAHM explain, TAZKIYAH respectful choices, KHIDMAH safe real-world activity with adult support. No faith score or replacement for human teacher.
## Teacher NPC
V0.1 selectable questions and vetted short answer cards, no unbounded generative chat. Offer a simple explanation, example and optional check. Unknown question -> say not available, invite discussion with a trusted teacher/parent. If later free-text added, review age/region restrictions, Roblox text filtering, privacy and moderation; no custom player-to-player chat or bypass of TextChatService; no personal information or off-platform contact. Human educators approve lesson content and sources before release.
## Celebration and family mode
Optional ceremony for completed learning units, non-accredited; no ranking, exclusion, purchases or public real names. Parents can independently try learning path, give optional feedback without personal student information. No requirement to create account outside platform. Follow linked parental controls and eligibility, no circumventing age or publication checks.
