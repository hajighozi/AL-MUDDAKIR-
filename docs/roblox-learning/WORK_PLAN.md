# SP-04 — Eksperimen Roblox pendidikan
Status PLANNED; rencana tersimpan, bukan implementasi. Branch khusus dari main. Mandat tercatat R149.1 dan instruksi penataan pengguna 27 November 2026.

Tugas: periksa dokumentasi platform, aturan usia, keamanan komunikasi, biaya dan izin; desain pengalaman belajar yang sesuai usia dan dapat dimainkan tanpa kontak dengan orang asing; uji dengan pendidik sebelum publikasi. Tidak meminta akun murid, tidak memublikasikan identitas atau membuat pembelian wajib. Tidak mengklaim integrasi Roblox atau game sudah dibuat.

## Gate
Sumber asli dan kebutuhan → rancangan → implementasi → tes nyata → review → PR ke staging bila layak. Catat perubahan satu commit logis per tahap. Jangan merge otomatis, force-push atau mengubah sejarah.
