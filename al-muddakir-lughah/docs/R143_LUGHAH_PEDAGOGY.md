# R-143 — Pedagogik Lughah (C/draft)
Nahwu, sharaf, balaghah sebagai alat membaca, bukan daftar istilah untuk dihafal saja. L0 mengenali; L1 membedakan; L2 menjelaskan; L3 menerapkan; L4 menimbang alternatif.
Unit LUG-P01 (ID usulan): mawdu kata dalam kalimat Arab sederhana, jihat kelas kata, mahmul isim/fiil/huruf. KU/source/evidence: contoh asli desain; rujukan kitab/edisi pending review. Tujuan: mengidentifikasi tiga kelas kata dalam contoh buatan كَتَبَ زَيْدٌ فِي الدَّفْتَرِ (Zaid menulis di buku catatan); model guru: كَتَبَ fiil, زَيْدٌ dan الدَّفْتَرِ isim, فِي huruf. 35 menit: baca 5, model 8, sorogan 10, contoh baru 7, umpan balik 5. Dialog: apa alasan pengelompokanmu? Praktik: kartu kata dan kalimat baru. Refleksi opsional; khidmah: menyimak teman dengan izin. Asesmen: klasifikasi, alasan, koreksi; alternatif lisan/tulis. Provenance: contoh buatan, bukan kutipan kitab. Validasi guru bahasa dan lokator primer pending.
