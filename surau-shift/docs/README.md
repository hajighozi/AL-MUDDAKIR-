## C. Ketentuan kerja
Hati, akal, amal dan lisan saling terkait; pembinaan sepanjang hayat. Ilmu fardhu 'ain sesuai kebutuhan kewajiban, bukan semua spesialisasi; tidak ada penetapan mazhab resmi. Khidmah dapat berjalan bersama tazkiyah. Tidak ada skor iman, paksaan, hukuman fisik, pengawasan batin atau afiliasi wajib. Rujuk register sumber R150.8A/B di raudhah-integrated. Status dokumen dan tingkat akses sumber tidak sama dengan validasi. Tahqiq, perlindungan anak, review manusia dan audit korpus asli belum selesai. Tidak ada merge atau perubahan main.
